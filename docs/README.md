## Documentation Rules

- Keep user and contributor documentation in `docs/`.
- Keep the repository root limited to standard GitHub entry documents.
- Remove outdated or duplicate explanations instead of stacking more files.
- Prefer GitHub Releases and CHANGELOG for release history over committed versioned release-note files.
