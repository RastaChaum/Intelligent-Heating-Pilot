## Documentation Layout Policy

- User and contributor documentation belongs in the [docs](docs) directory.
- The repository root should only keep standard GitHub entry documents such as README, CHANGELOG, CONTRIBUTING, and LICENSE.
- Release notes should live in GitHub Releases and CHANGELOG rather than versioned markdown files committed at the root.
